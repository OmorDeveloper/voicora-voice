Voicora: foreground service demo

Recorded on Android with the Voicora release build (package com.voicora.app, version 1.0.0). It shows each foreground service the app declares.

  1. 0:00, FOREGROUND_SERVICE_DATA_SYNC (network download): the user taps Download model, leaves the app, and the voice model keeps downloading with a progress notification.
  2. ~1:45, FOREGROUND_SERVICE_MEDIA_PROCESSING: the user sends a long text and leaves the app. Speech generation continues on the device with a progress notification and a Stop button.
  3. ~2:30, FOREGROUND_SERVICE_MEDIA_PLAYBACK: the user plays the generated speech and leaves the app. Playback continues and is controlled from the media notification.
