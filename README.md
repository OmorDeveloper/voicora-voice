# Voicora Voice

On-device voice model files for the **Voicora** Android app.

The app downloads these files once from this repository's [Releases](../../releases), checks every file against a
pinned SHA-256 fingerprint, and then works fully offline. No text or audio ever leaves the phone.

| Release | Contents |
| --- | --- |
| `v1.0` | `voicora-voice-v1.bin` (~92 MB) and 32 voice packs named `voicora-<name>-<language>.bin` (English US, English UK, Hindi) |
